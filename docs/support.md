## GitHub Discussions

If you have a question or need help with anything,
start a discussion in [General](https://github.com/smashedr/install-release/discussions/categories/general)
or [Q&A](https://github.com/smashedr/install-release/discussions/categories/q-a).

If you want to see a new feature, start a discussion in
the [Feature Requests](https://github.com/smashedr/install-release/issues/new?template=1-feature.yaml) section.

[:simple-theconversation: &nbsp; Start A Discussion](https://github.com/smashedr/install-release/discussions){ .md-button .md-button--primary }

## GitHub Issues

If you run into any problems or find a bug, please [open an issue](https://github.com/smashedr/install-release/issues).

**These reports are treated with the highest priority.**

[:simple-southwestairlines: &nbsp; Report an Issue](https://github.com/smashedr/install-release/issues){ .md-button .md-button--primary }
